
# ✊✌️✋ RockPaperScissorsJS

> Классическая игра «Камень, ножницы, бумага» против компьютера — прямо в браузере.

## 🎯 О проекте

Мини-игра на чистом JavaScript. Ты выбираешь один из трех вариантов, 
компьютер — случайный, а счет ведется до бесконечности. 

Проект создан как часть моего портфолио **PortfolioForge** — 
я собираю его постепенно, шаг за шагом.

## 🎮 Как играть

1. Открой `index.html` в браузере
2. Нажми на одну из кнопок: **✊ камень**, **✌️ ножницы** или **✋ бумага**
3. Смотри результат и счет внизу экрана

## 🛠️ Технологии

- HTML5
- CSS3 (стилизация кнопок и счета)
- JavaScript (Vanilla, без библиотек)

## 🧠 Что внутри (логика)

- Массив `options` с тремя вариантами
- Функция `play(player)` — обрабатывает ход игрока
- Компьютер выбирает случайно через `Math.random()`
- Проверка победы через условия `if / else if`
- Обновление счета через `textContent`
